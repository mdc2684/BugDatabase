# Contributing

Thanks for helping improve BugDatabase.

## Reporting bugs

Open an issue with the **Bug report** template. Include steps to reproduce and
your environment details.

## Pull requests

1. Fork the repo and create a feature branch.
2. Keep the code style simple — this project favors readability over cleverness.
3. Make sure `python app.py` still starts cleanly.
4. Describe the change clearly in the PR body.

## Code of conduct

Be kind and constructive. This repo is a learning project for many first-time
contributors.
